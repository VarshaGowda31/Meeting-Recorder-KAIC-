# KAIC AI - Meeting Recorder

A lightweight, zero-dependency AI Meeting Recorder built with Node.js and React.

## 🚀 1-Click Simple Run (Recommended)

Just double-click **[Run-KAIC-AI.bat](file:///d:/3semmca/kaic-ai/Run-KAIC-AI.bat)** in your project folder!

It will:
1. Automatically launch the backend SQLite server.
2. Automatically open your web browser to `http://localhost:5000`.

---

## 💻 Terminal Command

Or run via command line:
```bash
node server.js
```
Then open `http://localhost:5000` in your browser.
